# 抖音续火花控制台（Windows 端）

程序有两种运行模式，在设置里切换：

- 本地运行（默认）：内置引擎直接在本机跑，用 Playwright 驱动浏览器，不需要服务器；
- 连接远程服务器：连到 Linux 服务端（`lin端` 里的 FastAPI 服务），任务交给服务器执行，适合长期挂着。

## 快速开始

1. 双击 `DouyinFireConsole.exe`。第一次启动会在 exe 同级目录生成 `config.json` 和 `data/`。
2. 默认是本地模式，右上角显示「● 本地引擎」。
3. 进「账号管理」→「＋ 新增账号」：
   - 填账号 ID；
   - 点「扫码登录」。本地模式会弹出真实浏览器窗口，用抖音 App 扫码确认；
     弹出人机验证（滑块、点选图片）时，直接在浏览器窗口里用鼠标操作，
     验证通过后登录态自动保存并回填；
   - 填好友和文案。
4. 进「发送时间与文案」，先点「试运行」验证，再点「立即运行」，
   或者加好时间点等它自动发。

## 切到远程服务器

1. 点右上角「服务器设置」。
2. 选「连接远程服务器（Linux 自动化服务）」。
3. 填服务器地址、端口（默认 8765）、Token。Token 在服务器上执行
   `cat config.json`，看 `token` 字段。
4. 点「测试连接」。这个按钮会真的请求一次校验 Token，通过后再保存。
5. 右上角显示「● 已连接服务器」表示生效。

切回本地：服务器设置 → 选「本地运行（本机直接发送，无需服务器）」→ 保存。

地址填 `127.0.0.1` 时注意端口，别落在本地引擎占用的 18765-18804 段，
撞上会把请求打到本地引擎，出现「账号还是本地的、刷新没反应」。
程序检测到这种情况会弹警告。

## 数据放在哪

都在 exe 同级目录：

```text
DouyinFireConsole.exe
config.json          # 本地引擎配置（端口、Token、账号）
client_config.json   # 客户端设置（运行模式、服务器地址）
data/
├── storage_state/   # 各账号登录态（扫码产物）
├── tasks/           # 任务配置
├── artifacts/       # 运行结果
└── logs/            # 引擎日志
```

迁移或卸载就是整个文件夹拷走，数据跟着走。

## 常见问题

- 浏览器起不来：本机模式优先用系统 Edge/Chrome，没有就装一个 Edge。
- 二维码生成不出来：服务器 IP 或本机网络可能被抖音风控，改用 Cookie 登录。
  本机浏览器装 Cookie-Editor 导出 JSON，在账号对话框里粘到
  「或粘贴 Cookie JSON（Cookie-Editor 导出）」下面的输入框。
- 本地模式登录遇到人机验证：浏览器窗口会正常弹出，直接在窗口里拖滑块或点图片，
  验证过了登录会接着走。
- 远程模式登录遇到人机验证：服务器没有显示器，没法在浏览器里操作验证码。
  改在本机浏览器手动登录，导出 Cookie 后粘贴导入。
- 提示「Token 无效或未授权」：新版「测试连接」会校验 Token，服务器在线但 Token
  填错时会直接报错，保存时也会拦下错误的 Token。在服务器执行 `cat config.json`，
  把 `token` 的值（不含引号）粘进设置。
- 本地模式和远程模式的数据不互通，账号和任务各存一份，建议只挑一种用。

## 降低风控风险

- 已内置反自动化指纹、好友之间随机 30-90 秒停顿、小概率 2-5 分钟长停顿、
  调度时间随机抖动（0-30 分钟）。
- 一个账号一天一个发送时间点就够，文案多备几条随机用。
- 同一个账号别在多台电脑同时登录。
- 账号风险、合规责任和免责条款写在包根目录的 `免责声明.txt`，用之前先过一遍。
