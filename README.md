# 抖音自动续火花

给抖音好友续火花的自动化工具。到点自动发消息，一个账号可以配多条文案随机挑，支持多账号。

实现方式是浏览器自动化：Playwright 驱动一个真实的 Chromium 操作抖音网页版。登录一次把登录态存下来，之后都跑这个登录态，不去碰私有接口。

## 两个端

服务器端跑 Linux，FastAPI 加无头 Playwright。一台机器常挂，浏览器打开网页界面就能看任务和日志，`deploy.sh` 一条命令装成 systemd 服务。

Windows 端是 PySide6 写的桌面程序，解压双击 exe 就能用，引擎内置在本机，不用另外开服务器。

两端的 `app/` 和 `server/` 是同一份代码，不会出现两套逻辑。

## 功能

- 多账号管理，扫码登录，登录态存本地，文件权限收到 0600
- 每个账号可以配多条文案，发送时随机挑一条
- 定时任务带随机抖动，不会整点齐刷刷发
- 拟人停顿：好友之间 30-90 秒，小概率 2-5 分钟，单条消息间隔有下限
- 浏览器指纹一致性处理，降低被识别成自动化的概率
- 日志、任务结果和截图里的好友昵称统一脱敏成「好友01」「好友02」
- 可选的钉钉机器人通知，任务跑完推一条结果；不填就不会有任何外部请求
- 状态监控页，实时日志、历史记录、任务结果都能看

## 快速开始

服务器端要 Python 3.9 以上和一个能跑 Chromium 的环境：

```bash
bash deploy.sh --src /root/lin端
```

Windows 端解压 `抖音续火花_成品版_打开即用.zip`，双击 `DouyinFireConsole.exe`。

成品包在 `发行包/` 里，因为体积超了网页上传的上限被切成 4 个分卷，下载后把它们放在同一个文件夹，跑 `合并分卷.bat`（Linux / macOS 用 `sh 合并分卷.sh`）拼回完整 zip。附带 `下载说明.txt` 里写了校验用的 sha256。

## 风险

抖音的风控能识别自动化行为，限流、降权、要求重新验证、封号都有可能。程序里做了随机延时和指纹处理，只能降低概率，给不了保证。

自己学习、研究、维护自己账号的日常消息没问题。骚扰、垃圾信息、批量操作别人账号不行。完整条款写在 `免责声明.txt` 里，用之前过一遍。
