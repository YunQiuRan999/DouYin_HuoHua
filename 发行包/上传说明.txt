GitHub 上传说明

这个文件夹里的每一个文件都小于 20 MiB，可以直接用网页拖拽上传。

一、源码版
    抖音续火花_源码版.zip（0.20 MB），直接传进仓库。

二、成品版（绿色免安装）
    抖音续火花_成品版_打开即用.zip.part01 ~ part04
    成品版压缩包共 77.61 MB，超过 GitHub 网页单文件 25 MB 的上限，
    所以按字节切成 4 份，每份不超过 20 MiB。
    下载时把它们放进同一个文件夹，
    双击 合并分卷.bat（Windows）或执行 sh 合并分卷.sh（Linux / macOS），
    会拼回完整的 抖音续火花_成品版_打开即用.zip。

    合并后请核对体积：77.61 MB
    完整包 sha256：fcc9a705b5416c4e4fce5ce7385258408f683ea236904ae8becfd9d43c4ca638

三、更省事的做法
    GitHub 的 25 MB 限制只针对网页上传。成品版这种大文件建议走 Release：
    仓库页面右侧 Releases -> Draft a new release -> 把完整 zip 拖进附件区，
    单个附件上限远高于此，下载体验也更好。仓库里只放源码即可。
