抖音自动续火花 · 使用说明
================================================================

照着做就行，不需要懂编程。


----------------------------------------------------------------
一、这程序做什么
----------------------------------------------------------------

给抖音好友自动发消息，把火花续上。

两种跑法，选一种：

  A. 只在本机跑
     不买服务器，双击程序就能用。缺点是电脑得开着，关机就发不出去。

  B. 放服务器上跑
     Windows 端只当遥控器，任务在 Linux 服务器上执行，能一直挂着，
     本机电脑关不关都不影响。


----------------------------------------------------------------
二、包里有什么
----------------------------------------------------------------

成品包（打开即用）：

  deploy.sh         服务器部署脚本
  lin端/            服务器端程序
  win端/            Windows 端程序，里面是打包好的 DouyinFireConsole.exe
  使用说明.txt      就是这份文件
  免责声明.txt      用之前单独看一遍，风险和你担的责任写在里面
  LICENSE           许可协议，个人可以免费用，禁止商用

源码包：

  deploy.sh         同上
  lin端/            服务器端源代码
  win端/            Windows 端源代码，附 build.bat 与 requirements.txt
  免责声明.txt      同上
  LICENSE           同上

两个包的 lin端 内容一致，win端 一个是打包好的 exe，一个是源码。


----------------------------------------------------------------
三、用法 A：只在本机跑
----------------------------------------------------------------

1. 打开 win端 → DouyinFireConsole，双击 DouyinFireConsole.exe。

2. 杀毒软件可能拦一下。程序没做代码签名，报毒是误报，选「允许」或「信任」。

3. 打开后右上角显示「● 本地引擎」，表示本机的引擎已经起来了。

4. 左侧点「账号管理」，再点「＋ 新增账号」：
     账号名随便填，比如「我的号」；
     点「扫码登录」。本机模式下会弹出一个真实浏览器窗口，用手机抖音
     扫码确认；如果弹出滑块或点选图片，直接用鼠标在浏览器窗口里操作，
     验证过了会自己往下走；
     然后填要发的好友和内容。

5. 切到「发送时间与文案」，先点「试运行」走一遍，看提示是否正常。
   试运行不真发消息，只检查登录态和好友能不能打开。

6. 确认没问题后点「立即运行」真发一次，或者在上面加每天的发送时间点
   （比如 09:00），到点自己发。


----------------------------------------------------------------
四、用法 B：放服务器上跑
----------------------------------------------------------------

第 1 步  买服务器

  配置 2 核 2G 内存、40G 硬盘就够。系统选 Ubuntu 22.04，或者 CentOS 7/8。
  买的时候设的 root 密码记下来，后面要用。

  要买云服务器（阿里云、腾讯云、华为云都行）。虚拟主机不行，
  跑不了 systemd，也开不了端口。


第 2 步  上传文件

  把这两样放到服务器同一个目录里：

      deploy.sh
      lin端

  上传方式任选：

  用宝塔面板：装好宝塔后登录，左侧「文件」，进 /root，
  把 deploy.sh 和 lin端 文件夹拖进去。

  用 FinalShell / Xftp：连上服务器后，把两个东西拖到右侧 /root。

  deploy.sh 的文件名别改成中文。改成中文名传到服务器容易乱码，
  脚本就找不到了。


第 3 步  跑部署脚本

  在服务器上开一个终端（宝塔左侧有「终端」，FinalShell 下方也有），
  敲这一行回车：

      cd /root && sudo bash deploy.sh

  没有 root 权限就改用：

      bash deploy.sh --user

  用 --user 装的，后面所有 systemctl 和 journalctl 命令都要加 --user。

  然后等 3 到 10 分钟。中间会下载约 200MB 的浏览器内核，屏幕一直滚字，
  属于正常现象。

  看到下面这几行就算好了：

      部署完成，服务正在运行
      【连接信息】
        服务器地址： http://1.2.3.4:8765
        连接 Token： 1a2b3c4d5e6f7a8b9c0d1e2f3a4b5c6d

  上面是示例，以你自己屏幕上显示的为准。截图存下来，下一步要用。

  如果提示「没有找到服务器端源码目录」，说明 deploy.sh 和 lin端 没放在
  一起，放好再跑一次；也可以直接指定路径：

      sudo bash deploy.sh --src /root/lin端


第 4 步  Windows 端连过来

  1. 打开 win端 → DouyinFireConsole → DouyinFireConsole.exe。

  2. 点右上角「服务器设置」。

  3. 选「连接远程服务器（Linux 自动化服务）」。

  4. 填地址和 Token：
         地址：http://你的服务器IP:8765
         Token：第 3 步显示的那串

  5. 点「测试连接」。这个按钮会真的发一次请求校验 Token，
     连不上或 Token 不对就别保存，先把两项改对。

  6. 保存后右上角变成「● 已连接服务器」，就切过去了。

  7. 之后到「账号管理」加账号、扫码登录，和用法 A 一样，
     区别是二维码由服务器生成。

  想切回本机模式：还是「服务器设置」→ 选
  「本地运行（本机直接发送，无需服务器）」→ 保存。


第 5 步  放行端口

  到云服务器控制台，找到这台机器的「安全组」或「防火墙」，加一条规则，
  放行 TCP 8765。

  不放行的话 Windows 端一直连不上，提示连接失败。


----------------------------------------------------------------
五、常用命令（都在服务器上敲）
----------------------------------------------------------------

看服务状态：
    systemctl status douyin-fire

重启：
    systemctl restart douyin-fire

看实时日志（Ctrl+C 退出）：
    journalctl -u douyin-fire -f

看连接 Token：
    cat /root/lin端/config.json
    （lin端 不在 /root 下的话，路径换成实际位置）

停止：
    systemctl stop douyin-fire

卸载（data 目录会留着）：
    sudo bash /root/lin端/uninstall.sh

装的时候用了 --user，上面 systemctl 和 journalctl 都要加 --user。

六、常见问题
----------------------------------------------------------------

问：提示「未连接，Token 无效或未授权」？
答：Windows 端填的 Token 和服务器上的对不上。在服务器执行
    cat /root/lin端/config.json，复制 token 后面那串字符（不含引号），
    粘到「服务器设置」里保存。注意别带上空格。

问：测试连接成功，别的页面还是提示未授权？
答：用本包里的新版程序。旧版「测试连接」不看 Token，填错也报成功。

问：浏览器起不来，提示装 Edge 或 Chrome？
答：本机模式用的是系统自带 Edge，一般不用装。服务器端会自动装 Chromium。

问：二维码出不来，或者扫码登录失败？
答：服务器出口 IP 可能被抖音风控了，换个登录方式：在本机浏览器装上
    Cookie-Editor 插件，导出抖音 Cookie（JSON），在账号对话框里粘到
    「或粘贴 Cookie JSON（Cookie-Editor 导出）」下面的输入框。

问：服务器日志里写「无法启动持久化浏览器」？
答：服务器上的 lin端 是旧版本。用本包里的 lin端 覆盖上传，然后
    systemctl restart douyin-fire。

问：定时发的时间不准，差了几十分钟？
答：程序故意加了 0 到 30 分钟的随机延迟。每天卡同一秒发送容易被判定成
    机器人，这个延迟是故意留的，属于正常现象。

问：电脑关机了为什么还能发？
答：用的是用法 B，任务在服务器上跑。

问：本机模式和服务器模式的账号能共用吗？
答：不共用，两边各存一份。建议只挑一种用。

七、几件要注意的事
----------------------------------------------------------------

1. Token 等于密码，别发群里，别截图外传。

2. 一个账号一天设一个发送时间点就够。文案多备几条随机用，别一天发几十条。

3. 同一个抖音账号别在多台电脑上同时登录。

4. 程序只用于学习交流，不能商用。遵守抖音用户协议，别拿去骚扰或营销，
   后果自负。完整条款写在 免责声明.txt 和 LICENSE 里，用之前看一眼。

5. 出问题先看日志：本机在「状态监控」页的实时日志里看，
   服务器端执行 journalctl -u douyin-fire -n 50。
